# Ядро Apple //e для Karabas Go / Mini / Mini G

[English version](README.md)

Apple //e (enhanced) для плат семейства Karabas Go (Xilinx Spartan-6 XC6SLX25): порт ядра MiST [apple2efpga](https://github.com/gyurco/apple2efpga) в версии [NanoApple2](https://github.com/MiSTle-Dev/NanoApple2), с частями [Apple-II_MiSTer](https://github.com/MiSTer-devel/Apple-II_MiSTer).

Состояние: в работе (см. `docs/PLAN.md`). На плате пока ничего не запускается.
