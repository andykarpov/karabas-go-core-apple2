# Apple //e core for Karabas Go / Mini / Mini G

[Русская версия](README.ru.md)

Apple //e (enhanced) for the Karabas Go board family (Xilinx Spartan-6 XC6SLX25): a port of the MiST core [apple2efpga](https://github.com/gyurco/apple2efpga) as extended by [NanoApple2](https://github.com/MiSTle-Dev/NanoApple2), with parts of [Apple-II_MiSTer](https://github.com/MiSTer-devel/Apple-II_MiSTer).

Status: work in progress (see `docs/PLAN.md`, in Russian). Nothing runs on a board yet.
